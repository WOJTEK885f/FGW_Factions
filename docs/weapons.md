# Weapons

The table below contains the weapons featured in **Freeman: Guerrilla Warfare**, their real-world counterparts, and the corresponding weapons used in **Arma 3** along with the required mod. The goal is to provide the closest possible representation of the original game's arsenal while using existing Arma 3 content.
